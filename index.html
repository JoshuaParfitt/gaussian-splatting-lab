THE CORE IDEA
G(r) = e−4.5r²

Each point is rendered as a screen-facing sprite. The fragment shader maps distance from the sprite center to opacity using a Gaussian profile.

Scope: This is an educational Gaussian point-sprite renderer, not a full 3DGS reconstruction pipeline. It does not compute learned anisotropic covariance projections, spherical harmonics, or differentiable optimization.
